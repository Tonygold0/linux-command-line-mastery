# Linux Command Line Mastery

A hands-on Linux command-line learning project focused on developing practical Linux administration, networking, file management and Bash scripting skills for DevOps engineering.

## Project Overview

This project documents practical exercises completed using Ubuntu Linux through Windows Subsystem for Linux (WSL).

The objective was to build a strong foundation in Linux command-line operations and understand how Linux tools are applied in real-world DevOps environments.

## Learning Objectives

- Understand Linux filesystem navigation and management.
- Manage files, directories and permissions.
- Monitor system resources and processes.
- Create and manage Linux users and groups.
- Inspect network interfaces, connectivity and listening ports.
- Process text and analyse logs using Linux utilities.
- Understand Bash scripting and automation fundamentals.

## Project Tasks

### Task 1: File Management
Practised creating, copying, moving, renaming, deleting and inspecting files and directories.

Commands included:
`touch`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `less`, `head`, `tail`, `find` and `grep`.

### Task 2: Directory Navigation
Explored the Linux filesystem, absolute and relative paths, and important system directories.

Commands included:
`pwd`, `cd`, `ls`, `mkdir` and `tree`.

### Task 3: System Monitoring and Administration
Practised monitoring system resources, inspecting processes, managing users and groups, and configuring file permissions and ownership.

Commands included:
`ps`, `top`, `df`, `free`, `uptime`, `whoami`, `id`, `groups`, `useradd`, `groupadd`, `usermod`, `chmod`, `chown` and `sudo`.

### Task 4: Linux Networking
Inspected network interfaces, tested connectivity, identified IP addresses and examined listening sockets.

Commands included:
`ip addr`, `ping`, `ss` and `hostname -I`.

### Task 5: Pipes and Output Redirection
Practised capturing command output, redirecting errors, searching logs, sorting information and processing text.

Operators and commands included:
`>`, `>>`, `2>`, `|`, `grep`, `sort`, `uniq`, `awk` and `tee`.

### Task 6: Bash Scripting and Automation
Introduced Bash script creation and execution, variables, conditional statements and loops.

Concepts included:
- Shebang (`#!/bin/bash`)
- Variables and command substitution
- Conditional statements (`if`, `else`)
- File existence checks
- `for` loops
- Script execution permissions
